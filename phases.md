# AIRF 2.0 Workbook Edition — Production phases (ordered)​‍‍​‌‍‌‌‍‍‌‌‍‌‌‌‍‍‍‍‍‌‍‍‍‌‍‌‌‌‌‍‌‌‍‌​

Authoritative narrative: `../../SKILL.md` (Phase 0, Book Architecture, QA Checklist). This is the
ordered execution contract both agents follow; each phase ends at the named gate. Where this
projection and `SKILL.md` disagree, `SKILL.md` wins. Every gated message ends with the exact line
**Type Proceed**, and no advancement occurs without it.

1. **Phase 0 — Title analysis & specification.** Trademark and KDP-risk screen (exam/certification/
   curriculum brands are the highest-risk zone); language lock; niche analysis (discipline, scope,
   audience, competencies, adaptation profile); subtitle engine (6-8 options, one RECOMMENDED);
   auto-configuration (chapter count, exercises per unit, exercise-type mix of >=3 from the six-type
   library, expertise level, reference approach, line spacing, grayscale accent treatment); page-
   budget validation against the 150-page hard cap; single specification gate. Stamp the classification
   line into `book_lock.md` with `framework=AIRF 2.0 Workbook Edition`. → **Gate 1 (Accuracy) planning inputs +
   specification gate**. End on **Type Proceed**.
2. **Front matter.** Title page (generated author name, working subtitle); copyright + disclaimer
   page (~400 words, five components); Preface (exactly 1 page); How to Use This Workbook (exactly
   1 page, explains bands and answer key); Word auto-TOC. Front matter unnumbered; page numbering
   starts at the Introduction (printed page 1) via section break.
3. **Introduction.** 2 pages max, natural paragraphs only: Welcome; What You Will Learn;
   Prerequisites and Preparation; Success Tips; plus one cross-reference to How to Use.
4. **Practice units (repeat per chapter — atomic resume unit).** Each chapter is exactly 10 pages:
   concept briefing (<=0.5 page/section), Band 1 Foundation, Band 2 Development, Band 3 Mastery
   (labelled and genuinely ramped), unit checkpoint; 70-80% worksheet share; >=3 exercise types;
   B&W-safe tables; response spaces sized for handwriting; labelled images where they aid practice.
   Append to the rolling DOCX. → **Gate 2 (Structure)** then **Gate 3 (Layout & Formatting)**.
   End on **Type Proceed**.
5. **Conclusion.** Exactly 1.5 pages: recap, encouragement, concrete next steps, honest-review
   invitation.
6. **Back matter / appendices.** The complete answer key with worked solutions (mandatory);
   printable blank templates; progress tracker; glossary; quick-reference and conversion charts.
7. **Release QA.** Answer-key completeness sweep (every exercise answered, every problem worked
   step-by-step, model answers/rubrics for open items); key matches printed exercises one-for-one;
   page budget <=150 re-verified; trademark and content-standards sweep; full competency coverage;
   one rolling DOCX. → **Gate 4 (Release)**.

Atomic production/resume unit = one practice unit (Phase 4 chapter) or one named front/back-matter
section. Production resumes at `next_unfinished_item`; it never re-runs Phase 0 (trademark screen,
language lock, subtitle, and specification are locked).
