# AIRF 2.0 Popular Science Edition — Production phases (ordered)​‍‍​‌‍‌‌‍‍‌‌‍‌‌‌‍‍‍‍‍‌‍‍‍‌‍‌‌‌‌‍‌‌‍‌​

Authoritative narrative: `../../SKILL.md` (Phase 0, Book Architecture, QA Checklist). This is the
ordered execution contract both agents follow; each phase ends at the named gate. Where this file
and `SKILL.md` disagree, **`SKILL.md` wins**.

1. **Phase 0 — Title analysis & architecture lock.** Title Clearance Gate (language lock, live
   collision search, trademark screen, Title Clearance Report); subject analysis (field/subfield,
   10-20 central-question inventory, consensus map ESTABLISHED/FRONTIER/CONTESTED, audience and
   scope); 6-8 subtitle options (<=200 combined chars); auto-configuration (structure model, visual
   level, glossary/further-reading, pen name with NO invented credentials, Book Identity Code); TOC
   mapped to central questions with fixed figure points. Present the TOC and end with the standalone
   line "Type Proceed"; nothing is drafted until the operator types Proceed. Stamp the canonical
   line into `book_lock.md` with `framework=AIRF 2.0 Popular Science Edition`.
   → **Gate 1 (Architecture lock)**
2. **Phase I — Chapters (one at a time into the single cumulative manuscript).** Each explainer
   chapter runs the full six-stage sequence: hook question -> intuition-building -> mechanism ->
   evidence story -> implications -> wonder payoff. Every analogy states where it breaks; at least
   one HOW-we-know evidence story; numbers humanized but exact; consensus-band labels applied;
   figures at fixed points. Field-guide variant: identification entries in the locked field order.
   Each chapter handoff ends with the standalone line "Type Proceed".
   → **Gate 2 (Per-chapter, before each chapter is delivered)**
3. **Phase II — Manuscript completion.** Cross-chapter consistency (one value per constant, one
   spelling per species); glossary against every defined term; further-reading verified real; all
   time-sensitive claims dated and the science-currency note set; taxonomy re-verification for
   nature titles; mental-model build order intact after revisions. → **Gate 3 (Manuscript completion)**
4. **Phase III — Consensus-classification audit & release.** Claim-by-claim consensus audit;
   quantitative recompute of the full comparison set; mysticism/overclaim sweep across all text and
   metadata; disclaimers adapted and AI-disclosure recorded; rights sweep; eBook linked TOC, print
   index, credential-clean bio. → **Gate 4 (Consensus-classification audit + release)**

**Atomic production/resume unit** = one explainer chapter (Phase I), or one field-guide entry block for
the field-guide variant, drafted into the single cumulative manuscript. Production resumes at the next
unwritten chapter/entry; it **never re-runs Phase 0** (title clearance, consensus map, structure
model, pen name, and Book Identity Code are locked).
