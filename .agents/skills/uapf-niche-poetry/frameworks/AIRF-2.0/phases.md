# AIRF 2.0 — Production phases (ordered)​‍‍​‌‍‌‌‍‍‌‌‍‌‌‌‍‍‍‍‍‌‍‍‍‌‍‌‌‌‌‍‌‌‍‌​

Authoritative narrative: `../../SKILL.md` (Phase 0 — Title Analysis, Book Architecture, QA
Checklist). This is the ordered execution contract both agents follow; each phase ends at the
named gate.

1. **Phase 0 — Title analysis & auto-configuration.** Sub-genre classification (determines
   architecture); **Emotional Arc Declaration** (hard requirement — declared and locked at the
   section level before any content is generated); day-count extraction and lock for numbered
   collections; form declaration for fixed-verse collections; copyright & originality mode
   declaration; auto-configuration (reference style, risk level, cliche prohibition, variety quota,
   voice register, disclaimer). Output the Phase 0 Summary confirming Active Sub-Genre, Active
   Emotional Arc, entry count, form rules, copyright mode, risk level, and voice register before
   competitor research. Stamp the classification line into `book_lock.md` with
   `framework=AIRF 2.0`. → **Gate 1 (Originality and Copyright)**
2. **Front matter.** Half-title; full title; copyright (AIRF 2.0 + AI-image disclosure + epigraph
   permissions); disclaimer if healing/mental-health claims; dedication (optional); preface (~1 p,
   the emotional journey); How to Use (~1 p); automatic TOC; Introduction (begins as page 1, 1 page
   max for poetry-first collections).
3. **Body — sections mapped to the arc (repeat per section).** 4-8 sections, each mapping to the
   Active Emotional Arc; each section 8-20 poems (or numbered entries). Structural unit follows the
   Active Sub-Genre (daily affirmation = day number + affirmation + optional reflection/prompt;
   poem = complete unit; spoken word = performance script; etc.). Sections are not interchangeable.
   → **Gate 2 (Structure and Arc Delivery)**
4. **Quality, originality & cadence audit.** Cliche audit (Anti-AI Poetic Law); variety quota by
   collection size; present-tense verification for affirmations; cadence audit reading >=10% of
   each section's entries aloud; specificity test; healing disclaimer and live crisis resources
   where applicable. The Originality Auditor's finding is final; failing entries are replaced.
   → **Gate 3 (Quality, Originality, and Cadence Audit)**
5. **Back matter.** Closing Note (~1 p, closes the arc); Acknowledgments (optional); About the
   Author (pseudonym only, no invented credentials); Index of First Lines (poetry collections);
   Recommended Reading (5-10 real titles); Resources (verified crisis/therapy resources for grief,
   trauma, mental-health themes).
6. **Production & KDP readiness.** Front/back matter order; typography; intentional white space;
   images generated (abstract/painterly), captioned, alt-texted; automatic TOC; folios begin at
   Introduction; uniqueness audit; clean DOCX render with no broken stanzas or orphaned section
   titles. → **Gate 4 (Production and KDP Readiness)**

Atomic production/resume unit = one arc section (Phase 3, with its entries) or one named front/back-
matter section. Production resumes at `next_unfinished_item`; it never re-runs Phase 0 (Active
Sub-Genre, Active Emotional Arc, declared entry count, and form rules are immutable once locked).
