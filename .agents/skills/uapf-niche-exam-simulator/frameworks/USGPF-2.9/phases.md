# USGPF 2.9 — Production phases (ordered)​‍‍​‌‍‌‌‍‍‌‌‍‌‌‌‍‍‍‍‍‌‍‍‍‌‍‌‌‌‌‍‌‌‍‌​

Authoritative narrative: `../../SKILL.md` (Phase 0, Book Architecture, QA Checklist). This is the
ordered execution contract both agents follow; each phase ends at its named gate. An OV-EXSIM title
has NO instructional learning chapters: the body is the PRACTICE QUESTIONS division only.

1. **Phase 0 — Title analysis & auto-configuration.** Intake and signal verification (total count
   is the single operator setting); live trademark clearance (non-affiliation for protected exam
   names); Children's Category Research (OV-KIDS yield if signalled); mandatory live **Exam Format
   Research** → Exam Format Evidence record and profile lock (blocks generation); Language Profile
   Card; subtitle composition (states total with "Practice Questions"); byline (FNG); Title Design
   Signature (Catalog Variation Law); assessment plan (set count, questions per set, per-set type
   mix, domain mapping, content-fixed answer patterns, recorded seed); Auto Configuration Package.
   Close on the exact Proceed line and stop. → **Gate 1 (Configuration and Bank Blueprint)**
2. **Front matter.** Title page (verbatim title, subtitle with count, byline only); Copyright and
   Disclaimer (non-affiliation naming the exam owner); native TOC; How to Use This Book (exam
   format summary, timed-simulation instructions, score tracking, answer-key navigation),
   1.40–1.55 pages; folio begins here as Arabic page 1.
3. **Body — Timed Simulation Sets.** PRACTICE QUESTIONS division (Heading 1, new page); Practice
   Exam 1..N subheads (Heading 2, continuous, never new-page) each with an Instr timing line
   (item range, instruction convention, suggested time budget = researched exam time / item count);
   two equal columns for standard items, full-width break for scenario/exhibit items; items
   numbered continuously 1..total with no restart at set boundaries.
   → **Gate 2 (Per-Set Format and Content Audit)** after every set.
4. **Randomization engine.** Run the engine on the complete bank from the recorded seed; integrity
   check (text at each new key equals text at original key; option multisets match); Two Option Law
   (two-option in-sequence types carry cap ≥2, default 3); Answer Pattern Audit PASS on the built
   file. → **Gate 3 (Randomization Engine and Answers Division)**
5. **Answers and score interpretation.** ANSWERS AND EXPLANATIONS division mirrors every Practice
   Exam N one to one (two-column; every distractor addressed; ≤50-word content-based rationales;
   answers keyed to matching question numbers). SCORE INTERPRETATION GUIDE organized by descriptive
   performance band, no pass-probability claims, 1.40–1.55 pages.
6. **Appendices.** Appendix A Exam Blueprint Summary (domains + weighting from the evidence record,
   disclaimed as subject to change); Appendix B Time-Per-Question Budget (researched time limit /
   item count, with pacing strategies).
7. **Assembly & Final QA.** Section-length re-verify; two-pass Contents gate; strip sweep;
   contrast; byline exactly twice; non-affiliation present; no invented statistics anywhere;
   Operator Zero Correction Standard; release record written. → **Gate 4 (Final QA and Release)**

Atomic production/resume unit = one Practice Exam set (Phase 3), its mirrored answer group (Phase 5), or
one named front/back-matter section. Production resumes at `next_unfinished_item`; it never re-runs
Phase 0 (title, clearance, evidence record, profile, blueprint, content-fixed patterns, seed, and
design signature are locked at configuration).
