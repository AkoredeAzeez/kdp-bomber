# CBF 2.0 — Production phases (ordered)​‍‍​‌‍‌‌‍‍‌‌‍‌‌‌‍‍‍‍‍‌‍‍‍‌‍‌‌‌‌‍‌‌‍‌​

Authoritative narrative: `../../SKILL.md` (Phase 0, Book Architecture, Interior Design, QA
Checklist). This is the ordered execution contract both agents follow; each phase ends at the
named gate. Children's books are **page-architected**, not chapter-architected — the atomic unit
is the page/spread (or, for chapter/middle-grade, the chapter).

1. **Phase 0 — Title analysis & auto-configuration (Book Lock).** Title clearance (Amazon
   Children's search + trademark/IP screen); subject analysis and **age-band lock** in exact order
   (Hands → Intent → Reading mode → Band lock); pick exactly one host profile; subtitle to the
   gatekeeper; emit the Book Lock (concept, band + second lock, reading mode, host profile, trim,
   page target, ink/paper, bleed, word budget, type floor, art-to-text ratio, color mode, language
   + direction, originality transformations, deliverables). Present Book Lock, proceed on PROCEED.
   Character model sheet + style bible built before any page art. → **Gate 1 (Book Lock & Architecture)**
2. **Manuscript (per page/spread, then whole book).** Draft to the locked band budget; vocabulary,
   sentence length, and stakes inside the band; read-aloud pass for AB-0/AB-1 and all rhyme;
   Page-Turn Law on every narrative page; child-appropriateness battery; originality audit.
   → **Gate 2 (Manuscript)**
3. **Front matter.** Title/ownership page (thumbnail + 100% review); compact copyright with
   AI-disclosure status; contents page where it aids navigation; welcome page for function books.
4. **Interior production (per page/spread, then thumbnail sheet).** Layer stack on every
   illustrated page (bleed background → quiet zone/opaque panel → real typography → accents →
   folio); text zones honored; type at/above band floor, left-aligned, leading >=1.3; continuity
   against model sheet; color mode + palette lock + grayscale proof; thumbnail sheet and 100%
   render. → **Gate 3 (Art, Layout & Typography)**
5. **Back matter.** Story bands: optional "The End", author note to grown-ups, discussion
   questions. Fact/workbook bands: answer key, child-language glossary, certificate; series hook
   page if a series is planned.
6. **Print & release (whole book).** Even page count, >=24 pages, color-ink economics vs. live KDP;
   entire PDF at correct bleed size with parity-correct trim boxes and no crop marks; fonts
   embedded; images >=300 DPI; safe zones; cover wrap matches spine; AI-disclosure; physical proof
   ordered and inspected (proof is the color authority). → **Gate 4 (Print & Release)**

Atomic production/resume unit = one page/spread (story/fact/function books) or one chapter (AB-3
chapter/middle grade), or one named front/back-matter section. Production resumes at
`next_unfinished_item`; it never re-runs Phase 0 (age-band, trim, and language direction are
locked). Every correction reopens its own gate and all downstream gates with fresh evidence.
