# AIRF 2.0 Self-Help Edition — Production phases (ordered)​‍‍​‌‍‌‌‍‍‌‌‍‌‌‌‍‍‍‍‍‌‍‍‍‌‍‌‌‌‌‍‌‌‍‌​

Authoritative narrative: `../../SKILL.md` (Phase 0 — Title Analysis, Book Architecture,
QA Checklist). This is the ordered execution contract both agents follow; each phase ends at
its named gate.

1. **Phase 0 — Title analysis & auto-configuration.** In order (Steps 0.1–0.10): preserve title +
   detect language; extract seed words and assign OV-SELF sub-category and **risk tier (R4/R2/R1,
   highest present wins)**; preliminary trademark screen (GREEN/YELLOW/RED); Amazon competitor
   research (10–20 comparables) and recommended page target; typography + production profile
   (Step 0.5 table); author pseudonym; reference style (APA 7); five subtitle options; visual
   strategy. Emit the Phase 0 report ending with "Type Proceed to continue to the Table of
   Contents phase." → **Gate 1 (Safety & Compliance)** — tier assigned before any content.
2. **Front matter.** Cover handoff; title page; copyright page; tier-appropriate disclaimer;
   dedication (optional); preface (≈1 page); How to Use This Book (≈1 page; at R4 includes safety
   guidance + non-linear-reading permission + Crisis Resources pointer); live auto-TOC; folios
   start at Introduction. → **Gate 2 (Structure & Completeness)**
3. **Introduction.** Frame scope and limits by tier; first professional-referral notice (R4/R2);
   at R4 introduce the Crisis Resources appendix. Introduction begins on visible page 1.
4. **Chapters (repeat per chapter, tier-calibrated).** Each chapter follows the five-part formula:
   relatable opening scenario → concept introduction → evidence-aware explanation (verified sources,
   APA 7) → exercises/reflection (optional-exercise declaration at R4) → integration close. R4/R2
   carry a contextual professional-referral cue per chapter; R4 respects safety-before-processing
   pacing. → **Gate 3 (Evidence & Accuracy)** applied as chapters complete.
5. **Conclusion.** Approximately 1.5 pages; integrates lessons, reinforces realistic/non-linear
   expectations, introduces no new major concept; professional-help encouragement at R4/R2.
6. **Appendices (tier-mandated).** R4: Crisis Resources (verified live) + Exercises Reference +
   Recommended Reading/Professional Resources. R2: Worksheets/Trackers + Professional Resources.
   R1: Quick-Reference System Summary + Templates/Trackers/Worksheets. References section.
7. **Release QA.** Whole-book render page by page; page count within competitor-informed range;
   images inserted or fully prompted; visual-safety re-scan; anti-AI-language scan; voice/tier
   consistency; Word formatting and live TOC verified. → **Gate 4 (Production & Uniqueness)**

Atomic production/resume unit = one chapter (Phase 4) or one named front/back-matter section. the production agent
resumes at `next_unfinished_item`; it **never re-runs Phase 0** (title, risk tier, and
configuration are locked at Phase 0 and safety calibration depends on them).
