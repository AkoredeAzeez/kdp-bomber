name: uapf-correction-resume
description: Correct an existing UAPF project or resume it after interruption. Use when output is wrong, a gate failed, or a previous Codex thread ended.
---

1. Read the project state, decisions, locked specs, source/claim ledgers, outline,
   completed chapters, reviews, build log, and task log.
2. Identify the earliest incorrect decision or first incomplete gate.
3. Correct the governing source file before changing downstream outputs.
4. Mark all affected downstream files for revalidation.
5. Preserve correct material and locked details.
6. Rerun research and every affected quality gate.
7. Rebuild the rolling DOCX only after source files pass.
8. Continue automatically from the first valid incomplete gate.
9. Persist exact progress before ending.
