---
name: uapf-content-architecture
description: Build and validate the UAPF TOC, Introduction allocation, chapter briefs, page bands, back-matter reference plan, image map, and arrangement fingerprint.
---

1. Read Master Phase IV, the routed overlay, format appendices, locked Phase 0
   package, autopilot page requirements, and research gap map.
2. Allocate 2–3 pages to the Introduction.
3. Create a TOC that covers the promised scope without duplicated chapter jobs.
4. Enforce target pages per chapter, maximum total page count, chapter minimums,
   and assessment exceptions. Size the chapter and page budget so the book's
   projected total lands ON the target page count within 5% either way (global
   hard rule 21): sum the per-chapter page bands plus front/back matter and
   confirm the total sits inside [target-5%, target+5%] BEFORE drafting, so the
   book converges on the band instead of missing it at release QC. If the plan
   projects outside the band, adjust chapter depth/count (real content), not type
   size, until it fits. page_count_gate.py verifies the rendered result at QC.
5. Create one brief per chapter with outcomes, evidence needs, risks, visuals,
   page-band targets, dependencies, and completion criteria.
6. Reserve back matter for references and other required support material.
7. Run scope coverage, arrangement, originality, feasibility, page-budget, and
   source-presentation checks.
8. Correct failures, record `AUTO-PROCEED`, and start Phase V.
