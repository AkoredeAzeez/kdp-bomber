# UCGF 1.0 — Production phases (ordered)​‍‍​‌‍‌‌‍‍‌‌‍‌‌‌‍‍‍‍‍‌‍‍‍‌‍‌‌‌‌‍‌‌‍‌​

Authoritative narrative: `../../SKILL.md` (Book Architecture, QA Checklist). This is the
ordered execution contract both agents follow; each phase ends at the named gate.

1. **Phase 0 — Title analysis & auto-configuration.** Trademark + market screen; classify
   title (STRONG/WEAK/SATURATED/RISKY); lock title; language; recipe count; author identity;
   theme nutrient; categories; plan duration; design DNA (palette + archetype + divider +
   numerals + meta style); page projection via governor. Stamp the canonical classification
   line into `book_lock.md` with `framework=UCGF 1.0`. → **Gate 1 (Configuration)**
2. **Front matter.** Cover handoff; IMG-00 hero; copyright + medical disclaimer; preface (1 p);
   How to Use (1 p); live auto-TOC; folios start at Introduction. → **Gate 2 (Structure)**
3. **Introduction + Education.** Introduction (3 subsections); Educational Ch.1 (theme science,
   ≥2 named sources/claim); Educational Ch.2 (kitchen application, USDA-safe temps).
4. **Recipe chapters (repeat per category).** Full-bleed divider (IMG-D-<category>) with title
   band; recipe pages, two recipes/page in the locked archetype, one photo/recipe (IMG-Rnn),
   method restarts at 1, Per Serving ends with theme nutrient. → **Gate 3 (Per-Chapter)**
5. **Conclusion.** Exactly 1.5 pages, four movements, honest-review request.
6. **Appendix.** Food lists; day-by-day meal plan (every cell a book recipe); weekly shopping
   lists; USA/UK measurement charts.
7. **Release QA.** Whole-book page render; title character-match; silent-exclusion + em-dash
   scans; image contract complete; logs updated; one premium editable DOCX. → **Gate 4 (Release)**

Atomic production/resume unit = one recipe chapter (Phase 4) or one named front/back-matter section.
Production resumes at `next_unfinished_item`; it never re-runs Phase 0 (classification is locked).
