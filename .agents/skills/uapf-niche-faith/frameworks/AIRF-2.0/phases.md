# AIRF 2.0 — Production phases (ordered)​‍‍​‌‍‌‌‍‍‌‌‍‌‌‌‍‍‍‍‍‌‍‍‍‌‍‌‌‌‌‍‌‌‍‌​

Authoritative narrative: `../../SKILL.md` (Phase 0 — Title Analysis, Book Architecture, QA
Checklist). This is the ordered execution contract both agents follow; each phase ends at the
named gate.

1. **Phase 0 — Tradition declaration & auto-configuration.** Declare and lock the Active Tradition
   (HARD REQUIREMENT — no tradition, no output); title clearance (AIRF trademark screen plus
   faith-publisher series checks); extract and lock DECLARED UNIT COUNT from the title;
   sub-genre classification (Daily Devotional / Prayer Journal / Scripture Study Guide / Topical /
   Liturgical / Contemplative / Theological); auto-configure sacred text, default public-domain
   translation, Chicago reference style, risk level (R1 baseline, R4 for grief), voice register,
   and disclaimer. Output the Phase 0 Summary. Stamp the canonical classification line into
   `book_lock.md` with `framework=AIRF 2.0`. → **Gate 1 (Tradition & Copyright Integrity)**
2. **Front matter + structural scaffold.** Half-title, title, copyright (+ translation credit),
   faith-specific disclaimer, preface, how-to-use, Translation Acknowledgment page, automatic TOC;
   part/section groupings that sum to the declared unit count; Introduction begins as page 1.
3. **Devotional units (repeat per unit; group into parts, never generic chapters).** Each unit in
   the sub-genre's unit formula: Daily Devotional = Scripture -> Reflection (200-350 w) -> Prayer
   (50-120 w) -> Application (1-3 prompts); public-domain translation with correct citation;
   unit target 450-600 words excluding the quotation. → **Gate 2 (Day-Count & Structural
   Completeness)** then **Gate 3 (Theological & Safety Review)**
4. **Back matter.** Conclusion (~1.5 pages, no new doctrine); Scripture Index; optional Topical
   Index (200+ pages); Further Reading (8-15 titles); Crisis and Pastoral Support Resources
   (verified live); About the Author (pseudonym only).
5. **Production & KDP QA.** Front/back matter order; TNR 12 pt / 1.15; scripture block format;
   part-opener images at any page count (global Rule 11), each with caption and alt text; automatic TOC;
   numbering from Introduction; uniqueness audit; clean DOCX render.
   → **Gate 4 (Production & KDP Readiness)**

Atomic production/resume unit = one devotional unit (Phase 3) or one named front/back-matter section.
Production resumes at `next_unfinished_item`; it never re-runs Phase 0 (Active Tradition, declared unit
count, sub-genre, translation, and risk level are locked at Gate 1).
