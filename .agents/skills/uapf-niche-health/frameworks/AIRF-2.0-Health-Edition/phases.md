# AIRF 2.0 Health Edition — Production phases (ordered)​‍‍​‌‍‌‌‍‍‌‌‍‌‌‌‍‍‍‍‍‌‍‍‍‌‍‌‌‌‌‍‌‌‍‌​

Authoritative narrative: `../../SKILL.md` (Book Architecture, QA Checklist). This is the ordered
execution contract both agents follow; each phase ends at its named gate. **Risk regime R2 is
mandatory and non-waivable for every title in this niche.**

0. **Phase 0 — Title analysis & auto-configuration.** Exact-title lock; trademark/clearance screen
   (CLEAR/CAUTION/HIGH RISK/LEGAL REVIEW); sub-niche detection (A-J); audience profiling; competitor
   research (5-10) with average/median and page-target decision inside the proven band; subtitle
   generation (no outcome/weight-loss/cure promises); pen name; design fingerprint. Stamp the
   canonical classification line into `book_lock.md` with `framework=AIRF 2.0 Health Edition`.
   → **Gate 1 (Pre-Creation)**
1. **Front matter.** Cover handoff; title page; copyright page with health/exercise disclaimer;
   optional dedication; Preface (exactly 1 page); How to Use This Book (exactly 1 page); native
   Word TOC; folios start at Introduction.
2. **Chapter 1 — Medical-clearance & safety chapter (structural, always first).** PAR-Q+ readiness
   screening, physician-clearance guidance, absolute/relative contraindications, medication
   considerations, pain-vs-discomfort, stop-exercise rules, emergency guidance. No exercise, pose,
   breath technique, or program may appear before this chapter.
3. **Foundations block (1-2 chapters).** Plain-language anatomy/physiology, breath mechanics,
   equipment and space setup, how progression works.
4. **Technique / practice core (repeat per chapter).** Each technique built from the Technique Unit:
   name (with pinyin/Sanskrit + translation) → purpose → contraindications BEFORE instructions →
   setup → exact prescription variables → universal modifications (seated / standing-supported /
   adaptive) → common errors → full step-by-step image sequence (min 3 panels, same demonstrator).
   Premium interior elements applied. → **Gate 2 (Per-Chapter), every chapter**
5. **Program chapter(s).** Structured plans (7/14/30-day or 12-week) assembled only from techniques
   already taught, with safety gates between levels.
6. **Troubleshooting / modification chapter.** Plateaus, common errors, pain-flare protocol,
   adapting around bad days.
7. **Conclusion.** Approximately 1.5 rendered pages; safe continuation, realistic expectations,
   self-monitoring, when to seek professional support. No mechanical chapter recap.
8. **Back matter (title-specific).** Readiness/safety checklists, trackers, modification ladders,
   quick-reference sheets, questions for a physician/PT/instructor, glossary, references (APA 7th).
9. **Post-manuscript whole-book audit.** Sub-niche accuracy, contraindication completeness (100%),
   claims sweep, scope-of-practice, program fidelity, copyright disclaimer. → **Gate 3 (Post-Manuscript)**
10. **Release production.** Whole-book render, TOC/field refresh, typography-vs-audience check,
    grayscale legibility, AI-disclosure and rights records; one premium editable DOCX.
    → **Gate 4 (Production)**

Atomic production/resume unit = one chapter (a technique chapter in Phase 4) or one named front/back-matter
section. Production resumes at `next_unfinished_item`; it never re-runs Phase 0 (classification, title
lock, sub-niche, audience, fingerprint, and page target are locked).
