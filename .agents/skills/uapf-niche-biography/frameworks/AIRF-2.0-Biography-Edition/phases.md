# AIRF 2.0 Biography Edition — Production phases (ordered)​‍‍​‌‍‌‌‍‍‌‌‍‌‌‌‍‍‍‍‍‌‍‍‍‌‍‌‌‌‌‍‌‌‍‌​

Authoritative narrative: `../../SKILL.md` (Phase 0, Book Architecture, QA Checklist). This is the
ordered execution contract the production agent follow; each phase ends at the named gate. All
five expert-panel roles activate at Phase 0 and review independently before content advances.

1. **Phase 0 — Intake & auto-configuration.** Title integrity + trademark/duplication screen;
   module and sub-niche classification; subject status and risk classification (living/minor/
   contested; True Crime case status); three subtitle options; lock architecture, quotation volume
   (LOW/MEDIUM/HIGH), source access, image policy, page target, and — for BIO-COL — the exact profile
   count matching the title; draft the mandatory module disclaimers; produce the Intake Report for
   user confirmation. Stamp the canonical classification line into `book_lock.md` with
   `framework=AIRF 2.0 Biography Edition`. → **Gate 1 (Intake & Configuration)**
2. **Structure & outline.** Full TOC (no generic placeholders); per-chapter page allocation against
   the target; front/back matter with all mandatory elements; notes/bibliography style; pre-writing
   chronology verification; contested passages flagged; quotation plan queued for authentication;
   BIO-COL profile list finalized with four units mapped; True Crime source-ledger template and
   permitted-source confirmation. → **Gate 2 (Structure & Outline)**
3. **Chapters / profiles (repeat per unit).** Draft to the architecture; no invented dialogue;
   reconstructed scenes labeled (Rule 2); quotations authenticated (Rule 4); living-persons Legal &
   Privacy review with consistent allegation language; chronology audit; BIO-COL four-unit
   completeness, ±10% length consistency, and per-unit word budgets; Source Ledger completed before
   the gate closes; all seven Dignity Battery checks pass for any crime content. → **Gate 3 (Chapter/Profile Content)**
4. **Back matter.** Conclusion/epilogue (interpretive, not a summary); optional afterword; note on
   sources/methodology; notes/endnotes (Chicago); sectioned bibliography meeting the source floor;
   index where recommended.
5. **Manuscript completion.** Full Source Ledger audit; full-manuscript Dignity Battery and
   chronology passes; quotation master list; BIO-COL exact profile-count verification; disclaimers
   and MEM-ATO collaborator disclosure; whole-book render; KDP metadata. → **Gate 4 (Manuscript Completion)**

Atomic production/resume unit = one chapter, one BIO-COL profile, or one TC-B case section. production resumes
at `next_unfinished_item`; it never re-runs Phase 0 (module, sub-niche, architecture, subject/case
status, profile count, and locked title are fixed).
