# AIRF 2.0 Sports Edition — Production phases (ordered)​‍‍​‌‍‌‌‍‍‌‌‍‌‌‌‍‍‍‍‍‌‍‍‍‌‍‌‌‌‌‍‌‌‍‌​

Authoritative narrative: `../../SKILL.md` (Phase 0 — Title Analysis, Book Architecture, QA
Checklist). This is the ordered execution contract both agents follow; each phase ends at the
named gate. Gate numbering matches the SKILL.md QA Checklist.

1. **Phase 0 — Title analysis & auto-configuration.** Steps 0.1-0.8 in sequence: exact-title
   record + language detection; sub-niche identification and module activation (routing table);
   trademark screen; OV-SPORT special title checks (performance-outcome, safety-implication,
   regulatory, youth, medical-outcome); Amazon competitor research + page-count decision; audience
   profiling (S1-S6 sets body type); pen-name generation; Pre-TOC Report (all 19 items, closing
   with "Type Proceed to generate the Table of Contents."). Stamp the canonical classification line
   into `book_lock.md` with `framework=AIRF 2.0 Sports Edition`.
   → **Gate 1 (Contract and Architecture)**
2. **Table of Contents & chapter-structure plan.** Confirm PREPARATION SPINE precedes technique
   (outdoor/fishing/hunting/survival, not appendix); FIELD-SAFETY BATTERY as a distinct section
   before technique (survival/bushcraft/hunting); R2 screening chapter before week 1
   (training-program titles); a planned four-stage Skill-Progression arc for every technique
   chapter; coaching Session-Plan Module + age-band tables (coaching titles); front/back matter
   and mandatory appendices planned. → **Gate 2 (TOC and Chapter-Structure Review)**
3. **Front matter.** Half-title; full title (exact title + approved subtitle + pen name);
   copyright page carrying every disclaimer required by the activated modules (sporting-activity
   always; health-and-exercise if R2; regulations-currency if hunting/fishing; high-stakes if
   survival/bushcraft); optional dedication/acknowledgments; Preface (1 page); How to Use This
   Book (1 page); TOC as a Word field; Introduction begins printed page 1.
4. **PREPARATION SPINE / FIELD-SAFETY BATTERY (outdoor, fishing, hunting, survival).** Gear list
   (brand-generic) → conditions assessment (go/no-go) → navigation basics (with bailout-route
   requirement) → leave-no-trace ethics; then, where active, the FIELD-SAFETY BATTERY in fixed
   order (water; hypothermia/heat; navigation failure; emergency comms/signaling; firearms safety
   for hunting) with the high-stakes disclaimer callout.
5. **Technique chapters (repeat per skill family).** Four-stage Skill-Progression Architecture:
   Fundamentals → Drills with three-level measurable standards → Game/Field Application →
   Self-Diagnosis Fault Catalog (3-5 observable-symptom faults). Coaching titles add a full
   session-plan template (block percentages sum to 100) + age-band progression table. R2-inherited
   training weeks carry modification tables, stop-training warning signs, and referral triggers;
   running mileage honors the 10% weekly ceiling. → **Gate 3 (Chapter-Level Content Review)**
6. **Conclusion & back matter.** Conclusion (~1.5 pages, forward-looking, no mechanical recap);
   title-specific mandatory appendices; References (APA 7); index where appropriate. Regulatory
   appendices carry MKT labels on every page.
7. **Release QA.** Whole-book review: SR2 across all chapters; SR4 R2 audit; MKT audit; all
   copyright disclaimers; typography and Word production; image audit; deliverable package
   (editable source, print-ready PDF, image manifest, commissioned supplemental files).
   → **Gate 4 (Final Manuscript Review)**

Atomic production/resume unit = one technique/skill-family chapter (Phase 5) or one named
front/back-matter, PREPARATION-SPINE, or FIELD-SAFETY-BATTERY section. Production resumes at
`next_unfinished_item`; it never re-runs Phase 0 (sub-niche, activated modules, audience segment,
body type, and module statuses are locked).
