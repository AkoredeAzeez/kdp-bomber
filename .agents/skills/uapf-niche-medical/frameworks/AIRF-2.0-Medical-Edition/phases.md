# AIRF 2.0 Medical Edition — Production phases (ordered)​‍‍​‌‍‌‌‍‍‌‌‍‌‌‌‍‍‍‍‍‌‍‍‍‌‍‌‌‌‌‍‌‌‍‌​

Authoritative narrative: `../../SKILL.md` (Phase 0 — Title Analysis, Book Architecture, QA
Checklist). This is the ordered execution contract both agents follow; each phase ends at the
named gate. Where this projection and `SKILL.md` disagree, `SKILL.md` wins.

1. **Phase 0 — Title analysis & auto-configuration.** Title preservation + language detection;
   Eponym Audit and subject-scope analysis with a full resolution table; marketplace, jurisdiction
   and guideline localization; trademark + established-textbook collision clearance; learner-level
   calibration; five-dimension auto-configuration (audience; ABUNDANT visual + Hard Rule 22; R2
   mandatory; NO practice questions; clinical appendices); Book Identity Code with `+OV-MEDT`;
   TWO-COLOR palette; 6-8 subtitles; 3-5 credential-free pen names; locked TOC. Stamp the
   classification line into `book_lock.md` with `framework=AIRF 2.0 Medical Edition`. End on the exact line
   **Type Proceed**. → **Gate 1 (Phase 0 Clearance & Configuration)**
2. **TOC & architecture validation.** Confirm chapter count 10-20, per-chapter word budget
   (>=13,000 body words), eponym-free headings, case-based structure, 4-6 traceable objectives,
   3-5 named feature boxes, per-subchapter image plan, back-matter plan, zero assessment items.
   → **Gate 2 (TOC & Architecture)**. End on **Type Proceed**.
3. **Front matter.** Title page (pen name, no credentials); copyright page with full clinical
   disclaimer and AI-image disclosure; List of Figures; List of Tables; List of Abbreviations;
   linked TOC; Preface / How to Use. Roman numerals unnumbered; Arabic numbering starts at Preface.
4. **Chapter production (repeat per chapter — atomic resume unit).** Clinical-scenario opener +
   Learning Objectives Box; 4-6 numbered body sections with mechanistic depth; one photorealistic
   image per numbered subchapter under the six-part Safe-Vocabulary recipe (Hard Rule 22); generic
   drug naming with the formulary verification sentence on every dosing passage; R2 dual-source
   verification and 100% accuracy floor on high-stakes content; case-resolution close per Axis G.
   Append to the cumulative manuscript. → **Gate 3 (Per-Chapter)**. End on **Type Proceed**.
5. **Back matter.** Appendix A Drug Class Reference (generic only); Appendix B Normal Laboratory
   & Reference Values (source + date); further title-specific appendices; Clinical Glossary (no
   eponym primary entries); References (AMA, or APA 7 for nursing/allied health); Index; About the
   Author (no fabricated credentials).
6. **Release QA.** Whole-book eponym, drug-name, dosing, R2/accuracy-floor, and image audits;
   palette-consistency check; identity-code recording; em-dash scan; page render page by page;
   one navigable DOCX with an updateable TOC field. → **Gate 4 (Release)**.

Atomic production/resume unit = one chapter (Phase 4) or one named front/back-matter section. the production agent
resumes at `next_unfinished_item`; it never re-runs Phase 0 (title clearance, eponym table,
configuration, palette, and identity code are locked).
