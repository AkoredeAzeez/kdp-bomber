# AIRF 2.0 Reference Edition — Production phases (ordered)​‍‍​‌‍‌‌‍‍‌‌‍‌‌‌‍‍‍‍‍‌‍‍‍‌‍‌‌‌‌‍‌‌‍‌​

Authoritative narrative: `../../SKILL.md` (Phase 0, Book Architecture, QA Checklist). This is the
ordered execution contract both agents follow; each phase ends at the named gate. Where this file
and `SKILL.md` disagree, **`SKILL.md` wins**.

1. **Phase 0 — Title analysis & Book Lock.** Sub-type classification (REF-FACT / REF-TRIVIA /
   REF-LIST / REF-REF) with signal evidence; title integrity + count-claim audit; superlative and
   record inventory by tier; adult audience + depth calibration (OV-CFACT/OV-CHILD re-route check);
   subject domain + verification scope; auto-configuration (trim, ink/paper, bleed, page target,
   entry density, protocols); three subtitles; and the mandatory Book Lock output. Stamp the
   canonical classification line into `book_lock.md` with `framework=AIRF 2.0 Reference Edition`.
   → **Gate 1 (Title Analysis and Book Lock)**
2. **Phase I — Manuscript & verification.** Build all thematic sections / rounds / ranked entries /
   lookup entries in the locked entry-unit architecture; maintain the dual-source verification log
   for every entry; WHY-depth (REF-FACT); single-answer defensibility (REF-TRIVIA); stated criteria
   (REF-LIST); locked template (REF-REF); volatile inline date-stamping; duplicate-entry scan;
   count-claim reconciliation; front and back matter. → **Gate 2 (Manuscript and Verification)**
3. **Phase II — Interior design, layout & typography.** Trim/geometry; three font roles at the type
   floors; left-aligned body; answers-separation visual zone (REF-TRIVIA); sidebar law; spot/full
   color accessibility; index formatting; folios and running headers. → **Gate 3 (Interior Design)**
4. **Phase III — Preflight & pre-release.** Even page count in KDP range; final entry-count
   reconciliation against the claim; superlative re-audit; verification/duplicate/disputed logs on
   file; fixed-layout embedded-font PDF; physical proof; final KDP category/keyword/description.
   → **Gate 4 (Preflight and Pre-Release)**

**Atomic production/resume unit** = one themed section (REF-FACT), one round (REF-TRIVIA), one
contiguous block of ranked entries (REF-LIST), or one alphabetical/section block (REF-REF), plus
its verification-log rows. Production resumes at `next_unfinished_item`; it **never re-runs Phase 0**
(sub-type classification and Book Lock are locked).
