# CBF 2.0 — Production phases (ordered)​‍‍​‌‍‌‌‍‍‌‌‍‌‌‌‍‍‍‍‍‌‍‍‍‌‍‌‌‌‌‍‌‌‍‌​

Authoritative narrative: `../../SKILL.md` (Phase 0, Book Architecture, Interior Design, Content
Rules, QA Checklist). OV-CFACT is a specialization overlay of OV-CHILD: all OV-CHILD phases and
gates are inherited; where OV-CFACT tightens a rule (full-color requirement, dual-source
verification, fact-count reconciliation) the tighter rule governs. The atomic content unit is the
**themed fact-spread**, not the chapter.

1. **Phase 0 — Title analysis & Book Lock.** Age-band + knowledge-depth (KD-1..KD-3) extraction;
   route to host profile CB-FACT (confirm the content atom is a *fact*, narrative frame <= one-
   sixth of pages); lock trim (8.5 x 11 default); fact-count claim audit (record FACT COUNT CLAIM:
   [N] or NONE); superlative inventory with risk levels; Curiosity Map (4-8 sections, familiar ->
   surprising -> exotic -> wild frontier); auto-configure type floors, word/fact budgets, gloss
   density, color, bleed; generate subtitle; emit the mandatory Book Lock block. Proceed on PROCEED.
   → **Gate 1 (Title Analysis & Book Lock)**
2. **Manuscript + fact verification.** Write sections per the Curiosity Map; every spread built as
   the Fact-Spread Unit (header + anchor fact + supporting cluster + Wow Callout + optional Quick
   Quiz), max 8 facts/spread; dual-source verification log for every fact; superlative audit
   (volatile dated inline); Number Lock; concrete-example law; on-page glosses; count-claim
   reconciliation; back matter (glossary, source list, index, Further Reading); child-
   appropriateness battery incl. OV-CFACT extensions; final spread = best fact.
   → **Gate 2 (Manuscript & Fact Verification)**
3. **Front matter.** Title/ownership page, copyright, contents (required for CB-FACT),
   introduction/welcome spread framing the curiosity hook and navigation system.
4. **Interior design, art & layout.** Assign one distinct accent hue per section (AA contrast,
   colorblind sim); build each spread on the 12-layer template with reserved text zones stated
   before art; all headers/facts/callouts/quiz/gloss/captions/diagram labels as real embedded type;
   sidebar law (<=40% of spreads); consistent photo/illustration treatment; navigation badge;
   bleed-to-edge with correct parity; grayscale proof; thumbnail / 100% / spread reviews.
   → **Gate 3 (Interior Design, Art & Layout)**
5. **Back matter.** Glossary, age-appropriate source list (>=2 per major fact), index (required
   AB-3/KD-3; recommended KD-2 over 64 pages), Further Reading (3-5 per section), optional
   Fast-Facts summary.
6. **Production, preflight & release.** Even page count within KDP range; premium color <72pp /
   standard 72+; final fact-count reconciliation; volatile superlatives dated; PDF box geometry;
   fonts embedded; >=300 DPI; real-type preflight; physical proof reviewed; AI-disclosure; safety
   re-confirmed. → **Gate 4 (Production, Preflight & Pre-Release)**

Atomic production/resume unit = one themed fact-spread (or one named front/back-matter section). the production agent
resumes at `next_unfinished_item`; it never re-runs Phase 0 (band, KD, trim, and language direction
are locked). A fact correction reopens Gate 2 and all downstream gates for the affected spread
(verification log, gloss, Quick Quiz, source list, and glossary must all be reconciled).
