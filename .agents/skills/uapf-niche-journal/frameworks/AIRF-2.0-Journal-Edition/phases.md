# AIRF 2.0 Journal Edition — Production phases (ordered)​‍‍​‌‍‌‌‍‍‌‌‍‌‌‌‍‍‍‍‍‌‍‍‍‌‍‌‌‌‌‍‌‌‍‌​

Authoritative narrative: `../../SKILL.md` (Phase 0 — Title Analysis, Book Architecture, QA
Checklist). This is the ordered execution contract both agents follow; each phase ends at the
named gate. This niche has **no chapters** — the chapter is replaced by the PAGE SYSTEM.

1. **Phase 0 — Title analysis & auto-configuration.** Trademark + risk screen; language lock;
   Tier classification (1/2/3) with justification; subject analysis (activity, audience, physical
   context); risk-regime assignment (R0 for Tiers 1-2, R1-R4 by subject for Tier 3); dated vs
   undated determination (UNDATED default); subtitle engine (6-8 options, adopt one working
   subtitle); auto-configuration of trim, page count, page-system design, accent scheme, line
   style/spacing, audience print-size tier, and Tier-3 prompt count/architecture. Stamp the
   canonical classification line into `book_lock.md` with `framework=AIRF 2.0 Journal Edition`.
   → **Gate 1 (Specification)** — ends with Type Proceed.
2. **Master unit + special pages.** Build the repeating unit once (every field, label, line count,
   checkbox verbatim from the approved spec); field-label reality audit by the Subject-Matter
   Practitioner; render all special pages (front matter, how-to-use, references, Tier-3
   support/crisis pages); Tier-3 full prompt list (no duplicates, arc, regime compliance).
   → **Gate 2 (Unit approval)** — ends with Type Proceed.
3. **Interior assembly.** Duplicate the approved master programmatically to the repetition count so
   all units are structurally identical; place front matter (locked order) and back matter;
   enforce spread logic book-wide; run the mandatory 7-entry walkthrough audit.
   → **Gate 3 (Assembly)** — ends with Type Proceed.
4. **Release QA.** Final PDF preflight at exact trim; margins/gutter pass; spec (undated status,
   page count, trim) matches interior; spine width computed; trademark re-confirmed; R3-R4
   crisis-page positions; catalogue uniqueness; content-standards + em-dash sweeps.
   → **Gate 4 (Release)** — ends with Type Proceed.

Atomic production/resume unit = one named section: the master-unit build, a special-page section, or
the interior-assembly duplication pass. Production resumes at `next_unfinished_item`; it never re-runs
Phase 0 (Tier classification, risk regime, dating, and page-system spec are locked at Gate 1).
