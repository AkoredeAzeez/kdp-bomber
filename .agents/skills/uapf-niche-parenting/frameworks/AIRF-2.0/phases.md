# AIRF 2.0 — Production phases (ordered)​‍‍​‌‍‌‌‍‍‌‌‍‌‌‌‍‍‍‍‍‌‍‍‍‌‍‌‌‌‌‍‌‌‍‌​

Authoritative narrative: `../../SKILL.md` (Phase 0 — Title Analysis, Book Architecture, QA
Checklist). This is the ordered execution contract both agents follow; each phase ends at the
named gate.

1. **Phase 0 — Title analysis & auto-configuration.** Sub-genre classification (Step 0-A, sets
   architecture); marketplace + Active Medical Authority lock (0-B, AAP/NHS/CPS/RACP, never
   blended); title clearance / trademark screen (0-C); age-range extraction (0-D); auto-config
   (0-E): reference style APA 7, risk level R2 baseline (R3/R4 escalation topics), voice register,
   mandatory When-to-Call boxes, disclaimer. Emit the Phase 0 Summary. Stamp the canonical
   classification line into `book_lock.md` with `framework=AIRF 2.0`.
   → **Gate 1 (Authority and Evidence Integrity)**
2. **Front matter.** Half-title; full title; copyright; parenting/medical disclaimer; optional
   dedication; preface (1 page); How to Use This Book (1 page); automatic TOC; folios start at
   Introduction as page 1. → **Gate 2 (Structural Completeness)**
3. **Introduction.** Begins as page 1; establishes scope, audience, honest what-it-does-and-does-
   not-cover statement.
4. **Body chapters (repeat per stage / age-band, or per name-entry block).** Stage-based or
   age-band architecture for the Active Sub-Genre (trimester parts / month bands / age bands /
   developmental themes / method domains), or the fixed baby-name entry sequence. Every
   health-adjacent chapter carries a "When to Call the Professional" box (3-8 indicators, urgency
   level, Active Medical Authority thresholds); every milestone stated as a range with upper
   consultation threshold; neurodiversity acknowledged. → **Gate 3 (Voice and Safety Review)**
5. **Conclusion.** ~1.5 pages; celebrates the reader's commitment; integrates themes; directs to
   professional support; introduces no new advice.
6. **Back matter.** Milestone Reference Chart (developmental titles) as a Word table with Active
   Medical Authority citation; appendices (birth plan template, hospital bag checklist,
   immunization referral, screening resources, recommended reading); Resources and Referrals
   (verified live); back disclaimer page; About the Author (pseudonym, no invented credentials).
7. **Release QA.** Whole-book render; front-matter order and folio start; typography; image
   auto-rule (any page count → one chapter-opening image per chapter) with captions and alt text;
   uniqueness audit; live-verification of stats and resources; auto-TOC populated.
   → **Gate 4 (Production and KDP Readiness)**

Atomic production/resume unit = one body chapter (Phase 4) or one named front/back-matter section.
Production resumes at `next_unfinished_item`; it never re-runs Phase 0 (sub-genre, Active Medical
Authority, age band, and risk level are locked).
