## Hard rules — Do NOT break (titles only; full text in SKILL.md "Key Rules — Do NOT Break")
1. The project count stated in the title is the contract with the reader — every project present, complete, executable.
2. Safety callouts live inside the step where the hazard occurs, never only in the Introduction.
3. No registered brand names in instructional text (appendix supplier directory is the only exception).
4. Project Units must be self-contained.
5. The Project Visual Template is mandatory and non-negotiable.
6. Every step contains exactly one action; materials listed before Step 1.
7. Both metric and imperial measurements for every measurement.
8. Pattern abbreviations defined in front matter AND the glossary appendix.
9. Cultural techniques require cultural context attribution.
10. Design Signature logged before the TOC gate; differs from the last five (>=3 of 6 dimensions; no shared primary accent).
11. Visual continuity across step images is mandatory.
12. The anti-AI language protocol is non-negotiable.

## No deterministic ops module
This niche has no computable exact-math operations: the project count is taken verbatim from the
title (never calculated), page bands and section counts are advisory ranges rather than formulas,
and there is no answer-key/cell/budget reconciliation. All quality gates are expert-judgment,
safety, executability, and render inspections — see `validation.json` (all type=manual). No
`genie_crafts.py` is created.
