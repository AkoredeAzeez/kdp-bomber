# AIRF 2.0 Crafts Edition — Production phases (ordered)​‍‍​‌‍‌‌‍‍‌‌‍‌‌‌‍‍‍‍‍‌‍‍‍‌‍‌‌‌‌‍‌‌‍‌​

Authoritative narrative: `../../SKILL.md` (Phase 0, Book Architecture, Content Rules, QA Checklist).
This is the ordered execution contract both agents follow; each phase ends at the named gate.

1. **Phase 0 — Title analysis & auto-configuration.** Step 0-A trademark clearance (mandatory first
   action; CLEAR / CAUTION / BLOCKED verdict); 0-B craft sub-niche classification (primary + any
   secondary codes); 0-C project-count extraction (from the title only — never invented); 0-D
   audience & difficulty range; 0-E generate 7 subtitle candidates (all trademark-screened); 0-F
   auto-configuration (pathway, page band, visual density, font size, line spacing, Design
   Signature). Present configuration and request the Proceed confirmation. → **Gate 1 (Pre-Creation
   Foundation)**
2. **Phase 1 — TOC & structure.** Live TOC listing sections and all project titles; assign projects
   to Sections (by technique/skill/theme/material per sub-niche); size sections to the page band.
3. **Phase 2 — Front matter.** Title Page; Copyright Page (crafts-specific safety/liability
   disclaimer); Preface (exactly 1 page, Voice Persona); How to Use This Book (exactly 1 page:
   Project Unit template, difficulty scale, time/cost conventions, pattern notation); Introduction
   (begins on page 1, 1,500–2,500 words).
4. **Phase 3 — Project Unit generation (repeat per project).** For each project: Title, META line
   (Difficulty/Time/Cost), Hero image, Materials & Tools with quantities, numbered steps (one action
   each, step image per step, Safety Callout at each hazard step), Expected result, Project Facts
   Table. Enforce dual measurements, defined pattern abbreviations, cultural attribution, and the
   anti-AI language protocol. → **Gate 2 (Per-Project) checked continuously**
5. **Phase 4 — Section review (per section completion).** Section Divider (recto) with overview and
   preview thumbnails; expert sign-offs (Master Multi-Craft Coordinator; Textile Arts Specialist;
   Construction & Home Systems Authority); executability, facts-table accuracy, photorealism, visual
   continuity, and page-band conformance. → **Gate 3 (Post-Creation Section Review)**
6. **Phase 5 — Back matter.** Conclusion (1.5 pages); Appendix (all seven elements: difficulty
   index, materials master list, stitch/technique glossary, measurement conversion chart, supplier
   directory, project planner template, troubleshooting quick reference).
7. **Phase 6 — Final certification & KDP upload.** Confirm all N projects present and the count
   matches the title exactly; front-matter order and lengths; pagination starts at Introduction;
   Design Signature and two-color interior consistent; author-name consistency; 100% safety accuracy
   vs CPSC/OSHA/ANSI; cultural attribution validated; KDP categories; no AI-pattern language; cover
   wrap after interior lock. → **Gate 4 (Final Certification)**

Atomic production/resume unit = one complete Project Unit (or one named front/back-matter section).
Production resumes at `next_unfinished_item`; it never re-runs Phase 0 (trademark verdict, sub-niche
classification, project count, audience/difficulty, and Design Signature are locked).
