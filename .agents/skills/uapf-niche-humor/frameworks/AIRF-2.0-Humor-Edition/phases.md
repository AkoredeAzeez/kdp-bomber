# AIRF 2.0 Humor Edition — Production phases (ordered)​‍‍​‌‍‌‌‍‍‌‌‍‌‌‌‍‍‍‍‍‌‍‍‍‌‍‌‌‌‌‍‌‌‍‌​

Authoritative narrative: `../../SKILL.md` (Phase 0, Book Architecture, QA Checklist). This is the
ordered execution contract both agents follow; each phase ends at its named gate and the literal
gate line `Type Proceed.` No gate is skipped or merged.

1. **Phase 0 — Title analysis & evidence record.** Assign the Audience x Occasion x Pain Point slot
   (AUD-OCC-PAIN); draft three title+subtitle candidates (each combined <=200 chars); trademark
   clearance on all three (blocking); top-20 competitor scan; confirm one Humor + one Self-Help
   category; score the slot on the five-criteria rubric and apply the proceed/justify/kill decision;
   state seasonal window and manuscript-locked-by date. Stamp the classification with
   `framework=AIRF 2.0 Humor Edition` into the state ledger. → **Gate 1 (Evidence Record)**
2. **Phase 1 — Auto-configuration.** Auto-select audience segment, one locked humor register, body
   size and line spacing (senior override where needed), mascot-or-spot-art decision, pen name,
   three KDP categories, seven draft keywords; confirm trim 6x9, page target 80-120, chapter count
   8-12. Present one Auto-Configuration Package. → **Gate 2 (Auto-Configuration Package)**
3. **Phase 2 — TOC contract.** 8-12 chapter titles (each a joke) with subtitle jokes; ghost-numeral
   TOC layout, no page numbers; dedication/preface/how-to-use/introduction plans. → **Gate 3 (TOC Contract)**
4. **Phase 3a — Front matter.** Half-title; copyright with humor disclaimer; dedication (<=30 words);
   preface (1 p); How to Use (1 p, ends "that is the whole system"); TOC; folios start at the
   Introduction as printed page 1. → **Gate 3a (Front Matter)**
5. **Phase 3b — Chapters (repeat per chapter).** Locked beat blueprint: opener, quote page, hook,
   subchapter 1 (escalation), list device, subchapter 2 (the honest turn), warm closing beat,
   optional value element. Hold the register; meet joke-type diversity and image quotas; body
   600-900 words. → **Gate 3b (Chapter Quality Gate, per chapter)**
6. **Phase 3c — Assembly.** Conclusion (1 p); author bio (60-90 words); neutral review-request page;
   whole-book format pass (6x9, mirrored margins, gutter at final count, fonts embedded); extent
   80-120 pages. → **Gate 3c (Assembly Gate)**
7. **Phase 4/5 — Cover, metadata & release QC.** Three cover candidates (A/B/C); listing description
   within 4000 chars; seven keywords under 50 chars each; price in band with computed royalty; A+
   modules; interior/cover preflight; rights and AI-disclosure honest status. → **Gate 4 (Release QC)**

Atomic production/resume unit = one chapter (Phase 3b) or one named front/back-matter section. the production agent
resumes at `next_unfinished_item`; it never re-runs Phase 0 (slot classification and register are
locked). The register lock is immutable for the full manuscript — no tonal drift across chapters.
