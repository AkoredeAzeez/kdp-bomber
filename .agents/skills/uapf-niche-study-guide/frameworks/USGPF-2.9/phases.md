# USGPF 2.9 — Production phases (ordered)​‍‍​‌‍‌‌‍‍‌‌‍‌‌‌‍‍‍‍‍‌‍‍‍‌‍‌‌‌‌‍‌‌‍‌​

Authoritative narrative: `../../SKILL.md` (Phase 0, Book Architecture, QA Checklist). This is the
ordered execution contract both agents follow; each phase ends at its named gate.

1. **Phase 0 — Title analysis & auto-configuration.** Title verbatim intake; live trademark
   clearance (non-affiliation queued for protected exam names); children's-audience routing
   (OV-KIDS override if signalled); mandatory live **Exam Format Research** → Exam Format Evidence
   record and profile lock; **Examination Scope Research** → blueprint (domains + weighting);
   marketplace-integrity modifier for region-locked exams; subtitle composition (states total
   with "Practice Questions"); Language Profile Card; Title Design Signature (Catalog Variation
   Law); byline (FNG); assessment plan (set count, questions per set, set→chapter map, seed);
   Auto Configuration Package. Close on the Proceed gate and stop.
   → **Gate 1 (Configuration and Contents Contract)**
2. **Front matter.** Title page (48pt title, subtitle with count, byline only); Copyright and
   Disclaimer (non-affiliation + composite educational/jurisdiction disclaimer); native live TOC;
   folios begin at Introduction. → contributes to Gate 2.
3. **Introduction (exam orientation unit).** Always precedes every content chapter: what the exam
   is, its official structure, blueprint mapping, practice-set philosophy, study cycle,
   jurisdiction close. Measured 1.40–1.55 rendered pages; no image prompts.
4. **Learning chapters (repeat per blueprint domain).** Chapter template: title (H1), Learning
   Objectives box (exact lead line), intro prose, How to Use This Chapter box, subchapters
   (definition → mechanism → applied example → examiner relevance) with Exam Tip / Common Mistake
   boxes, ≥2 captioned tables, ≥2 content figures, Key Points close. Each chapter 6–10 pages;
   running total held under the 60-page ceiling. → **Gate 2 (Per-Chapter)** after every chapter.
5. **Practice divisions (consolidated).** PRACTICE QUESTIONS division (all sets consecutive,
   two-column, continuous numbering 1..total), then the randomization engine run from the recorded
   seed, then ANSWERS AND EXPLANATIONS (answers never adjacent to questions; ≤50-word teaching
   explanations). → **Gate 3 (Assessment)** per set / engine run / answers division.
6. **Back matter.** Conclusion (1.40–1.55 pages, never opening "In conclusion"); Glossary
   (alphabetical two-column premium table); Suggested Readings (real sources + candidate bulletin);
   Appendix A Examination Day Checklist, Appendix B calculation quick reference, Appendix C key
   thresholds.
7. **Final QA & Release.** Syllabus-coverage audit (blocking); item-format fidelity re-check;
   two-pass Contents gate; section-length re-verify; contrast/folio/strip sweeps; marketplace
   integrity; byline and truthful-status inspection on the actual built file. → **Gate 4 (Release)**

Atomic production/resume unit = one learning chapter (Phase 4), one practice/answers set (Phase 5), or
one named front/back-matter section. Production resumes at `next_unfinished_item`; it never re-runs
Phase 0 (title, clearance, evidence records, profile, blueprint, seed, and design signature are
locked at configuration).
