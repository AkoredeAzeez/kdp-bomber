# USGPF 2.9 — Production phases (ordered)​‍‍​‌‍‌‌‍‍‌‌‍‌‌‌‍‍‍‍‍‌‍‍‍‌‍‌‌‌‌‍‌‌‍‌​

Authoritative narrative: `../../SKILL.md` (Phase 0 — Title Analysis, Book Architecture, QA
Checklist). This is the ordered execution contract both agents follow; each phase ends at the
named gate.

1. **Phase 0 — Title analysis & auto-configuration.** Intake + signal verification; **Direction
   Declaration** (SOURCE + TARGET languages and both regional variants — the hard requirement that
   blocks every other Phase 0 step until locked); Register Scope; Script & Typographic Profile;
   Pronunciation System Declaration; Title trademark clearance (live); Children's category research
   (routes OV-KIDS if signals present); Language Profile Card; subtitle composition; byline (FNG
   live); Title Design Signature (catalog-distinct); unit plan (Applied Linguist reviewed); Auto
   Configuration Package closed by presenting the TOC plan and the standalone line "Type to
   proceed." Stamp the classification line into `book_lock.md` with `framework=USGPF 2.9`.
   → **Gate 1 (Configuration checks)**
2. **Front matter.** Title page; Copyright and Disclaimer (notes regional variant); Table of
   Contents (native field, levels 1-2); Introduction (1.40-1.55 pages: how to use, pronunciation
   guide, script overview, register labels, study cadence). Folios begin at Introduction as page 1.
3. **Communicative units (repeat per unit).** Each unit follows the fixed six-element order:
   Communicative Goal box → Dialogue (8-16 turns) → Vocabulary Block (20-40 items) → Grammar Point
   (exactly one; 3-5 examples) → Drills (3-5) → Cultural Note (100-150 words). Every target-language
   string audited by the Domain Master (native speaker of TARGET) for zero machine-translation
   artifacts. Unit length 4-8 pages on render. → **Gate 1 (Per-unit native-speaker audit)**
4. **Back matter.** ANSWER KEY (every drill item, grouped by unit and drill number); GLOSSARY (all
   vocabulary introduced, alphabetical bilingual); APPENDIX A (verb conjugation tables); APPENDIX B
   (pronunciation reference); APPENDIX C (real, verifiable suggested resources). → **Gate 2 (Back
   Matter)**
5. **Contents & assembly.** Two-pass Contents gate (printed folios equal actual, no "undefined");
   TOC lists Introduction, every unit (H1) and its six elements (H2), ANSWER KEY, GLOSSARY, each
   appendix; non-Latin script re-verified on the full assembled artifact; strip sweep. → **Gate 3
   (Two-Pass Contents and Assembly)**
6. **Final QA.** Full gate register re-run; contrast >= 4.5:1 on every pair; byline in exactly two
   interior locations; Appendix C citations confirmed real; no invented claims; Operator Zero
   Correction Standard; release record written. → **Gate 4 (Final QA)**

Atomic production/resume unit = one communicative unit (Phase 3) or one named front/back-matter section.
Production resumes at `next_unfinished_item`; it never re-runs Phase 0 (Direction Declaration, Language
Profile Card, and all Phase 0 locks are immutable once stamped).
