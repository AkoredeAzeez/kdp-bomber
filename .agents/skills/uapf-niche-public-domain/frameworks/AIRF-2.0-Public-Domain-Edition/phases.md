# AIRF 2.0 Public Domain Edition — Production phases (ordered)​‍‍​‌‍‌‌‍‍‌‌‍‌‌‌‍‍‍‍‍‌‍‍‍‌‍‌‌‌‌‍‌‌‍‌​

Authoritative narrative: `../../SKILL.md` (Phase 0 — Title Analysis, Book Architecture, QA
Checklist). This is the ordered execution contract both agents follow; each phase ends at the
named gate. Where this file and `SKILL.md` disagree, **`SKILL.md` wins**.

0. **Phase 0 — Legal Gate FIRST, then title analysis.** Nothing — not a subtitle, not a TOC, not
   one annotation — is produced until the Legal Gate passes.
   - **0.1 The 7-Point Legal Verification Checklist (HARD GATE):** author death date (>=2 sources);
     US publication date (before production_year - 96 is PD; 1930-1977 requires conclusive renewal
     analysis); EU/DE life+70; UK life+70; translation copyright (the specific translation must
     independently clear); illustration copyright (each plate independently PD or newly created);
     edition-specific additions copyright (no in-copyright editorial layer). **Failure at ANY point
     STOPS the project.** Output the Legal Verification Report: point-by-point PASS/FAIL with
     evidence and dates, the exact source text (edition, year, provenance), the marketplace list,
     and one status: CLEARED FOR [marketplaces] or STOPPED.
   - **0.2 Title clearance:** language lock; live title-collision search (report competitive field
     size); trademark screen (WIPO/USPTO/EUIPO, Nice classes 16/9/41, avoid classics-imprint trade
     dress); title format law (differentiator baked into title/subtitle per KDP PD policy).
   - **0.3 Subtitle generation** (6-8 options, differentiator + audience truthfully named).
   - **0.4 Auto-configuration:** edition type; value-add layer (substantial by the floor); audience
     & reading level; pen name (editor framing) + Book Identity Code.
   - **0.5 TOC:** front matter + the classic's own preserved structure + value-add apparatus + back
     matter. Present the TOC; end with the standalone line **Type Proceed**.
   → **Gate 1 (Legal + architecture lock)**
1. **Front matter.** Title page ("[Classic] by [Author]; Edited with an Introduction by [Pen
   Name]"); copyright page (copyright in new material only + PD statement); source-text statement;
   Note on the Text (source, what modernized, what untouched); optional chronology.
2. **Critical introduction.** 3,000-8,000 words, original, verified facts, spoiler warning if it
   discusses the ending.
3. **The text + apparatus units (repeat per unit).** Base text faithful to the identified source,
   original structure preserved; annotation layer (if annotated); illustration layer (if
   illustrated, credited in a List of Illustrations); each unit collated against the source.
   → **Gate 2 (Per-unit)** on every unit.
4. **Back matter.** Glossary; discussion questions (8-12 per section or 20-40 whole); further
   reading (verified real works only); About the Editor (no invented credentials).
5. **Manuscript completion.** Full collation; note numbering resolves; intro facts re-verified;
   glossary/questions coverage; **mandatory legal re-verification (all seven points re-run)**;
   copyright page correct. → **Gate 3 (Manuscript completion)**
6. **Differentiation audit + release.** Explicit differentiation statement mirrored in metadata;
   differentiator keyword in title/subtitle; description leads with the value-add; competitive
   distinctness; final rights sweep; eBook linked TOC and two-way note links. → **Gate 4 (Release)**

Atomic production/resume unit = one apparatus unit / annotated chapter (Phase 3) or one named front/
back-matter section. Production resumes at `next_unfinished_item`; it **never re-runs Phase 0** — the
Legal Verification, source-text identification, edition type, and Book Identity Code are locked.
(The Gate 3 legal re-verification is a completion check, not a Phase 0 re-run.)
