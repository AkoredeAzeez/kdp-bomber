# AIRF 2.0 History Edition — Production phases (ordered)​‍‍​‌‍‌‌‍‍‌‌‍‌‌‌‍‍‍‍‍‌‍‍‍‌‍‌‌‌‌‍‌‌‍‌​

Authoritative narrative: `../../SKILL.md` (Phase 0, Book Architecture, Content Rules, QA Checklist).
This is the ordered execution contract both agents follow; each phase ends at its named gate.

1. **Phase 0 — Title analysis & intake.** Title integrity + trademark screen; sub-niche
   classification (13-code matrix, primary + optional secondary); three subtitle options; lock
   auto-configuration (period scope, geographic scope, audience, tone register, Contested Status
   flag, Quotation Volume, Primary Source Access, image policy, page target); select and lock the
   architecture (A chronological / B thematic / C biographical); activate the expert panel; produce
   the Intake Report and get user confirmation. Stamp `framework=AIRF 2.0 History Edition` into the state
   ledger. → **Gate 1 (Intake & Configuration)**
2. **Phase I — Structure & outline.** Full Table of Contents (chapters + front + back matter);
   scoped chapter titles with date ranges/thematic pillars; per-chapter page allocation; image/map
   markers; confirm citation style; pre-verify chronology; flag contested chapters and queue the
   quotation plan. → **Gate 2 (Structure & Outline)**
3. **Chapter content (repeat per chapter).** Opening hook, historical context block, narrative or
   analytical core, primary-source integration, interpretive commentary, bridge transition. Apply
   quotation authentication, contested-event protocol, presentism guard, chronology audit, and
   regional-perspective review. All four (or five) panel roles review before the gate closes.
   → **Gate 3 (Chapter Content, per chapter)**
4. **Manuscript completion & release.** Full-manuscript chronology audit; quotation master list;
   contested topics re-checked; bibliography (primary/secondary/archival, minimum source count for
   the page length); notes; glossary when 10+ terms; captions and rights; mandatory disclaimer;
   full-panel critical analysis; front/back matter order; word count vs. page target; KDP metadata
   (description, seven keywords, categories). → **Gate 4 (Manuscript Completion)**

Atomic production/resume unit = one chapter (Gate 3) or one named front/back-matter section. the production agent
resumes at `next_unfinished_item`; it never re-runs Phase 0 (sub-niche, scope, and architecture are
locked, and architecture must not change mid-manuscript — a change stops the run and restarts from
Gate 2 with a reissued TOC).
