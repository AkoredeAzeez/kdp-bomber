# generate-book​‍‍​‌‍‌‌‍‍‌‌‍‌‌‌‍‍‍‍‍‌‍‍‍‌‍‌‌‌‌‍‌‌‍‌​

Generate a complete KDP manuscript to house standards, then assemble a premium
DOCX. First apply the `hard-rules` skill (`.agents/skills/hard-rules/SKILL.md`).

## Require before starting (ask if any is missing, never invent it)
- Exact book title (preserve it verbatim).
- Approved table of contents (this is the production contract).
- Format and category (for example: low-content journal, study guide, cookbook,
  children's book, self-help). This drives structure and interior design.
- Trim size and target page range.
- Any manuscript already written and the blueprint for chapters still to write.

## Load the niche framework first
If this studio is installed inside Genie (a `../AGENTS.md` exists), use Genie's
authoritative niche skill at `../.agents/skills/uapf-niche-<category>/SKILL.md`,
and obey the project's locked `book_lock.md` classification if one exists.
Otherwise, read the bundled copy in `niches/uapf-niche-<category>.md`.
Read the framework before drafting and follow its architecture,
interior design system, content rules, and QA gates. Bundled niches: health,
cookbook, textbook, medical, workbook, study-guide, exam-simulator, childrens,
childrens-facts, activity, crafts, selfhelp, howto, humor, history, fiction,
public-domain, travel, user-guide, journal, faith, business, biography,
parenting, sports, language, poetry, reference, popular-science.
Use the niche framework for structure and house design. Skip its live-research
and Phase 0 market steps: this agent has no browser, so the operator supplies
the title, contents, and positioning.

## Size the plan to the target page count (operator directive 2026-08-18)
Before drafting, budget the chapters so the finished book will land ON the
target page count within 5% either way. Sum the per-chapter page bands plus
front and back matter and confirm the projected total sits inside
[target-5%, target+5%]. If it does not, adjust chapter depth or count (real
content), never the type size. The finished book is verified in Genie with
`page_count_gate.py`; a rendered count outside the band is a production failure,
so converge on the target here rather than discovering the miss at the end.

## Draft
- BUILD CHAPTER BY CHAPTER WITH ROLLING JOIN AND AUTO-ADVANCE (binding
  operator rule, reaffirmed 2026-08-17): produce exactly ONE chapter at a
  time. Finish the chapter (prose and formatting; images come in the batch
  after the full manuscript per IMAGE TIMING below), then JOIN it
  to all previous chapters in the ONE rolling manuscript DOCX (chapters
  1..N in order, each starting on a new page): the rolling file always
  contains everything written so far, never a lone chapter. Run the gates
  (format QA, niche checklist, editorial), render, and deliver the PREVIEW
  as BOTH a DOCX and a PDF download. Then AUTOMATICALLY CONTINUE to the
  next chapter WITHOUT WAITING for any confirmation: on this engine
  auto-advance is the DEFAULT; the preview delivery itself is never
  skipped, and the operator can interrupt at any time. Drafting multiple
  chapters in one pass, delivering a batch at once, or stopping to ask
  "proceed?" between chapters are all production failures.
- Write complete, professional chapters strictly along the approved contents.
- Keep continuity with earlier chapters.
- Deliver every promised element: tables, worksheets, questions, answer sections,
  recipes, exercises, and closing elements. Preserve all verified counts.
- Match the category's interior design: styled chapter openers, a colored
  typographic system, tinted callout panels, styled tables, and white-space
  discipline. Grayscale-legible.
- BUILDER STUDIOS: for activity-niche books inside Genie, puzzles are
  GENERATED BY CODE with `../.agents/skills/uapf-puzzle-studio/`
  (word_search_gen.py, verified answer ledger) and coloring pages pass
  the mechanical line-art gate
  `../.agents/skills/uapf-coloring-studio/lineart_qa.py` before
  assembly. Never hand-write puzzle grids.
- NICHE FORMAT GATE (binding, 2026-08-17): inside Genie, run
  `python ../.agents/skills/uapf-quality-gates/niche_gate.py <project> --init`
  at project start, then record pass/fail/na WITH EVIDENCE for each item of
  the routed niche's checklist as you verify chapters, and run the gate
  before every phase advance: it must exit PASS. The niche SKILL.md's
  interior/architecture rules are the law being checked; read that file
  BEFORE drafting chapter 1, and design every unit page to its niche
  architecture (recipes per page, response space, text-safe zones, project
  page anatomy) rather than a generic layout. Standalone installs walk the
  bundled niche file's QA checklist by hand with the same evidence notes.
- UNIT DENSITY AND TRUTH (binding, 2026-08-17): for repeating-unit books
  (projects, recipes, puzzles), every unit page must fill its live area
  (enrich the unit or repaginate; no half-empty pages), steps and materials
  are written per unit and name that unit's actual design (identical
  boilerplate across units is a production failure), diagrams must depict
  the named design from its own geometry (never one template recolored),
  and materials are real purchasable specs (never hex codes as thread or
  paint colors).
- EDITORIAL PASS: when this studio runs inside Genie (a `../AGENTS.md`
  exists), run the editorial gate on every finished chapter before its
  preview ships: `python ../.agents/skills/uapf-editorial-pass/readability.py
  <chapter> --audience <band>` and `python
  ../.agents/skills/uapf-editorial-pass/catalog_similarity.py --file
  <chapter>`. A FAIL means rewrite (vary rhythm, cut stock phrasing,
  remove cross-book overlap) and re-run. Standalone installs without the
  scripts apply the same standards by hand: no stock AI phrasing, varied
  sentence rhythm, no prose shared between books.
- Where the content needs an image, write an image brief and generate it with
  your NATIVE built-in image tool, no API key (portrait 1024x1536 for full-page art, 1024x1024 for
  spot art). Caption every image as Figure C.N. Generate image calls at REDUCED
  reasoning for speed (`codex exec -c model_reasoning_effort="low"` when driven
  headlessly; the render quality is unchanged). IMAGE TIMING (operator directive
  2026-08-20): write the FULL manuscript text first (chapter previews ship
  text-only), THEN generate ALL the book's images in one batch and embed them
  before the book is finished. You MAY still generate natively inline while
  drafting if that suits a single-agent run, but images are never required per
  chapter. Images stay COMPULSORY for the FINISHED book: at finish, the whole
  book must carry every planned image, verified inside Genie by `format_qa.py
  <final.docx> --require-images N` (placeholders FAIL); a book is never complete
  imageless. If image generation fails, repair or fall back per
  uapf-image-engines codex_image_repair before finishing.
- IMAGE REALISM (binding, 2026-08-17): real-world subjects (food, crafts,
  tools, technique steps, places) render PHOTOREALISTICALLY or as technically
  accurate diagrams: correct proportions, real materials, natural lighting,
  no plastic AI sheen, no clip-art filler. State the realism requirement in
  every brief, then CHECK each generated image against its caption: if it
  does not clearly depict what the caption claims, REGENERATE it. Stylized
  looks only where the locked design fingerprint calls for them.
- FORMAT QA GATE (binding, 2026-08-17): after assembling each chapter and
  rendering its PDF, run (inside Genie)
  `python ../.agents/skills/uapf-quality-gates/format_qa.py <chapter.docx>
  --pdf <chapter.pdf> --trim <trim>` and fix every FAIL before the preview
  ships. Standalone installs without the script apply the same checklist by
  hand: no em dashes, type floors respected, 28pt+ chapter titles at 8.5x11,
  no hex codes as materials, no template-stamped sentences, unit pages
  filled.

## Assemble
- Build the rolling DOCX with `scripts/book_assemble.py` (uses python-docx).
- Insert generated images at their captioned positions inside the margins.

## Finish
- PAGE-COUNT GATE (binding, 2026-08-18): once the whole book is assembled and
  rendered, verify the final page count is within 5% of the target, either way,
  in Genie: `python ../.agents/skills/uapf-quality-gates/page_count_gate.py
  --project <folder> --docx <final.docx>`. A count outside [target-5%, target+5%]
  is a failure; repair by adding or trimming real content (not blank pages, not
  type below the floor) and re-render until it passes. Standalone installs
  without the script check the count by hand against the same band.
- Do not publish and do not claim the book is finished. End with a RETURN TO GENIE
  note listing what still must happen in Genie: research and claim gates, final
  house-style images, cover, watermark, quality control, and publishing.
